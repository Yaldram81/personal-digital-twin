# Failure Modes

## Memory Failures

- Irrelevant retrieval
- Over-reliance on recent data
- Missing long-term context

---

## Model Failures

- Hallucinated personal facts
- Over-personalization
- Generic responses due to weak retrieval

---

## System Failures

- Vector DB mismatch
- Context overflow
- Embedding drift over time

---

## Mitigation Strategies

- Re-ranking memory results
- Confidence scoring
- Multi-source validation before response generation
