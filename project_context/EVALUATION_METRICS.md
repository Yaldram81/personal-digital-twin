# Evaluation Metrics

## Memory Accuracy
- % correct retrieval of relevant past data

## Behavioral Consistency
- How closely output matches user style

## Prediction Accuracy
- Accuracy of preference/decision predictions

## Latency
- Response time under load

## Retrieval Quality
- Precision@K for memory search

---

## Success Thresholds

- Memory recall accuracy > 75%
- Response consistency score > 80%
- Latency < 2s for standard queries
