# Project Intent

## Core Objective
This project is a Personal Digital Twin system designed to model user behavior, preferences, and decision patterns using LLMs, embeddings, and memory systems.

## Non-Goals
- Not attempting full human consciousness replication
- Not building general AGI
- Not simulating emotions with psychological accuracy

## Success Definition
The system is successful if it can:
- Retrieve relevant past user context accurately
- Generate responses consistent with user writing style
- Predict simple user preferences and decisions
- Improve over time with added memory

## Primary Users
- Single-user system (initially)
- Expandable to multi-user architecture in future

## Design Philosophy
- Simplicity over complexity
- Modular architecture
- Memory-driven intelligence
- Explainable behavior over black-box outputs
